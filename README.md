# proyecto-final-estructuras
# Proyecto Final - Red Social Académica

## Descripción

Sistema desarrollado en C++ y Java que simula una red social académica universitaria utilizando estructuras de datos avanzadas.

El proyecto permite:

- Cargar estudiantes desde CSV
- Buscar estudiantes por ID
- Gestionar conexiones académicas
- Administrar proyectos/publicaciones
- Generar rankings académicos
- Comparar rendimiento entre C++ y Java

---

## C++
